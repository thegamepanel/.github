# Code of Conduct

## Our Standards

This project is a welcoming space for everyone. We expect all participants to:

- Be respectful and considerate in all interactions
- Accept constructive feedback graciously
- Focus on what is best for the community, and the project
- Show empathy towards other community members

We will not tolerate:

- Harassment, abuse, or personal attacks of any kind
- Discriminatory language or behaviour
- Deliberate intimidation or trolling
- Any behaviour that makes people feel unwelcome

## Scope

This code of conduct applies to all project spaces, including GitHub issues, pull requests, discussions, and the Discord
server.

## Enforcement

Instances of unacceptable behaviour can be reported by contacting the project maintainer directly. All reports will be
reviewed and handled appropriately. The maintainer reserves the right to remove, edit, or reject contributions and to
ban anyone who violates these standards.
